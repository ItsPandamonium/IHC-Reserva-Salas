# Prototipo de media fidelidad

Este apartado presenta el prototipo de media fidelidad de la plataforma de reserva de salas de reuniones, desarrollado en Figma.

El prototipo contempla seis pantallas:

1. Inicio.
2. Calendario de reservas.
3. Formulario de reserva.
4. Resumen de reserva.
5. Confirmación de reserva.
6. Mis reservas.

Las pantallas se encuentran conectadas para representar el recorrido principal del usuario, desde la consulta de disponibilidad hasta la confirmación de una reserva.
