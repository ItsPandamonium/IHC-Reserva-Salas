# Registro de avances del proyecto

## Proyecto
Diseño de una plataforma web para la reserva de salas de reuniones.

## Decisiones de diseño

- Se seleccionó un calendario interactivo como elemento principal de la plataforma.
- Se utilizó la metáfora de una agenda digital.
- Se definieron seis pantallas para representar el proceso de reserva.
- Se utilizó Figma para elaborar la propuesta visual y el prototipo.
- Se mantuvieron archivos y evidencias organizados en el repositorio.
