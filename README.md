# IHC-Reserva-Salas

Diseño de una plataforma web para la reserva de salas de reuniones, aplicando principios de Interacción Humano-Computador. Proyecto académico - Unidad 2, asignatura Interacción Humano Computador (eINGT1022-01).

**Integrantes:** Yessenia González, Renato Messina, Diego Vásquez.

## Resumen del proceso de diseño

1. **Descubrimiento de requisitos:** problema, usuarios (funcionario y administrador), contexto de uso, tarea principal y requisitos RF-01 a RF-07 y RNF-01 a RNF-04.
2. **Diseño de alternativas:** calendario interactivo (A) vs. asistente paso a paso (B). Se seleccionó A, complementada con elementos de orientación de B.
3. **Modelo conceptual y metáfora:** agenda digital basada en salas, horarios, disponibilidad y reservas.
4. **Tipos de interacción:** manipular, explorar, instruir, responder y conversar (limitado).
5. **Arquitectura de información y flujo:** Inicio, Reservar sala, Mis reservas y Administración.
6. **Diseño visual y emocional:** jerarquía, legibilidad, consistencia, retroalimentación y sensación de control.
7. **Prototipado:** prototipo navegable de media fidelidad en Figma (6 pantallas).
