# Documentación del proyecto

Esta carpeta contiene la documentación del proceso de diseño
de la plataforma de reserva de salas de reuniones.

- `Informe_Unidad2_...docx`: informe completo con los requisitos, las alternativas de diseño, el modelo conceptual, la metáfora, los tipos de interacción, la arquitectura de información, el diseño visual-emocional, el prototipado y el uso de GitHub.
- `Resumen_Unidad2_...docx`: archivo resumen con la síntesis del proyecto.
